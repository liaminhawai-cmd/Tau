# Historical depth-page proposal

The initial editorial work reorganised the page around “How deep is Tau?” for
technical readers who have not played. The proposed sequence introduces a move,
works through a tactical example, then asks what strength differences, search,
opening diversity and first-player results establish. An index and a separate
methods/data section make the long report easier to navigate.

The self-play league is relevant evidence for a skill ladder, with the limits
that ratings depend on opponents, search budget, the evolving pool and sample
size. Distinguish a game from a two-game colour-swapped match. A successful
learner or deeper search beating a baseline supports exploitable skill
structure; it does not measure an absolute strategic ceiling or prove balance.
The jiu-jitsu/chess ranges analogy is useful motivation when grounded in a Tau
position, rather than used as a numerical comparison between unrelated ratings.

[depth-proposal.html](depth-proposal.html) preserves the local editorial and
interactive proposal from this review thread. It is a historical snapshot,
not an update to current live results. Subsequent depth-page editions were
merged in [PR #10](https://github.com/liaminhawai-cmd/Tau/pull/10),
[PR #13](https://github.com/liaminhawai-cmd/Tau/pull/13) and
[PR #15](https://github.com/liaminhawai-cmd/Tau/pull/15), with corresponding
Pages-branch updates. Those later revisions must be considered before reusing
this proposal. The published page remains [tau-game.com/depth](https://tau-game.com/depth).

## Local discrete vertex repair
For a fixed vertex V, let w = hub_xy - V_xy and let lambda be the clean hubV correction. With no floor, cap or intervening pushes,

    w_post = (1 + lambda / |w|) w_pre.

Therefore every fixed linear tangential coordinate b obeys

    b_post = (1 + lambda / |w|) b_pre,

not b_post = b_pre. The new research-only `hubv-vertex-map.js` encloses this multiplier using the outward-rounded arithmetic layer. It also encloses the one-push shell identity

    d_post^2 = D^2 + (D-d)^2 (1/hf^2 - 1).

This is conditional on the input intervals and one fixed-vertex push. It does not certify feature ownership, exclude subsequent contacts, or close the engine floating-point gap. It is deliberately not enabled as a whole-substep checker shortcut.

## Conditional continuous theorem
Assume throughout an interval:
1. the victim hub contacts one fixed material vertex of the attacker polyline;
2. no other constraint binds;
3. the continuous least-motion law applies, without engine floor/cap/snapshot branches;
4. the unilateral reaction is nonnegative;
5. the vertex remains the closest feature.

Use t as nonnegative swing progress in radians and sigma in {-1,+1} as the swing direction. Let the planted pivot be P. The horizontal vertex trajectory is

    V(t) = P + r (cos gamma(t), sin gamma(t)),
    gamma(t) = gamma0 + sigma t.

Its height h is constant. With victim hub height H and required 3D separation D, define

    L = sqrt(D^2 - (H-h)^2) > 0.

The active gap constraint is exactly |q_xy - V| = L. Write

    q_xy = V + L n(psi),
    n(psi) = (cos psi, sin psi).

The contact Jacobian has zero theta component. Minimizing the mass-metric speed subject to the active gap derivative gives

    theta' = 0,
    q_xy' = n (n dot V').

Proof: differentiating the constraint gives n dot q_xy' = n dot V'. Among vectors with this fixed normal component, the unique minimum-norm vector has zero tangential component. The rotational coordinate is unconstrained and its minimum-cost derivative is zero. This proves the formula, rather than inferring it from numerical agreement.

Differentiate q_xy = V + L n and take its tangential component:

    psi' = -(e_t(psi) dot V') / L
         = -sigma (r/L) cos(psi-gamma).

Let beta = psi-gamma and k = r/L. Then the whole regime is governed by ONE autonomous scalar equation:

    beta' = -sigma (1 + k cos beta).

The victim's orientation stays constant; x and y are reconstructed algebraically. This is stronger than a generic 3-coordinate ODE for this particular regime.

## Closed-form solution without tangent poles
With z = tan(beta/2), the scalar equation becomes

    z' = -sigma/2 [(1+k) + (1-k) z^2].

Use projective coordinates z = u/v and solve the constant linear system

    [u]' = B [u],
    [v]      [v]

    B = [[0, -sigma(1+k)/2],
         [sigma(1-k)/2, 0]].

Then [u(t),v(t)]^T = exp(tB)[u0,v0]^T and beta = 2 atan2(u,v), interpreted modulo 2pi. This avoids treating a tangent-coordinate pole as a physical singularity. B^2 = (k^2-1) I/4, so the exponential uses hyperbolic functions for k>1, trigonometric functions for k<1, and a linear expression for k=1.

The reaction condition is n dot V' >= 0. At a negative reaction the equality-constrained regime is invalid and must release. The smooth scalar field has unique local solutions; the explicit formula continues until a genuine regime event.

## Event walls
For the incoming segment u = V - V_prev and outgoing segment z = V_next - V, the local vertex normal-cone conditions are

    w_3D dot u >= 0,
    w_3D dot z <= 0.

They are necessary and sufficient for endpoint ownership on those two adjacent segments. They do not by themselves exclude all nonadjacent features. Other contacts, nonadjacent ownership, reaction release and rim crossing must also be checked.

Numerical event isolation predicts the outgoing wall at about 4.33465850479 additional degrees from this ideal initial condition. At that wall the sampled other-contact gap is about 0.394595 units. No first-event ordering or event time has been interval-certified. The event probe checks adjacent cone walls and other-contact gaps; it is not an exhaustive event verifier.
